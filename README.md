## 👨‍💻 About Me

I'm a **.NET Software Engineer** with **3+ years of experience** designing and delivering production-grade **Enterprise ERP and CRM platforms** using **ASP.NET Core, Entity Framework Core, SQL Server, and RESTful APIs**.

I focus on turning complex business operations into maintainable, high-performance backend systems grounded in **Clean Architecture** and **SOLID Principles**—with strong attention to data integrity, security, and scalability. Beyond shipping production code, I enjoy **mentoring aspiring backend developers** and guiding them through real-world architecture and best practices.

### 🎯 Core Engineering Focus
- **Backend & API Design:** Designing modular, versioned RESTful APIs and real-time services with ASP.NET Core & SignalR.
- **Enterprise Domain Modeling:** Translating multi-module business workflows (Accounting, Inventory, HR, Claims, CRM) into clean domain models.
- **Database & Performance:** Structuring relational schemas in SQL Server, optimizing EF Core queries, and ensuring transactional consistency.
- **Security & Integrations:** Implementing JWT authentication, Role-Based Access Control (RBAC), and reliable third-party service integrations.
